# DigitalMe — 原始需求重建（2026-10-14）

## 0. 文件性質
本文件是從專案創辦者與 AI 的歷次需求討論整理的 **Original Intent / Product Requirements**；它是使用者需求，不是已開發功能、人格模型保證或死亡後自主意識的宣稱。因 Repo 原本為空，沒有可比對的舊版程式碼。

## 1. 為什麼要做
創辦者希望能夠將自己親自說話的聲音、影像以及與孩子相處的方式保存下來，讓孩子在未來依舊能透過對話，聽到熟悉的聲音、看到熟悉的形象，並接觸本人真正留下的故事與價值觀。核心是**陪伴、保存、傳承、可查證**；不是取代真實家人，也不是假裝數位分身有本人意識。

## 2. 初期原始需求（歷史脈絡）
- R-01 錄下自己的中文自然聲音、清理與轉檔，保存原始母檔。
- R-02 使用 XTTS 等可在 Mac mini 上運作的 voice cloning 模型，輸入任意文字產生本人聲音。
- R-03 能用故事、短句及完整文章測試合成音色、速度、情緒與發音；支援多句批次合成。
- R-04 不是只生成錄音：孩子要能與 **ChatGPT 類對話 AI** 進行真正多輪交談，再由本人的聲音播放回覆。
- R-05 語音輸入以麥克風採集，VAD / STT 可辨識語句；回覆要自動播放。
- R-06 螢幕上有一個**漂浮的人頭**；從本人正面照片或自己授權的影像生成，嘴型隨語音動，逐步增加眼睛、表情與頭部運動。
- R-07 未來可製作獨立 App / 網頁或搭配家中 Mac mini、Raspberry Pi；Mac 是本地推論主機。
- R-08 將來透過本人的故事、影像、錄音、書寫與回憶建構個人知識庫，使回覆不僅是 generic ChatGPT。
- R-09 盡可能使用免費、開源與本地執行技術，避免聲音資產被 SaaS 廠商綁死。

## 3. 目前有證據的原型成果
- 使用者已自行在 macOS 的 `~/xtts_project` 建立 Python 3.11 venv 與 Coqui XTTS v2。
- 本人原始聲音由 `George_Voice.m4a` 轉成 `George_Voice_converted.wav`，供 XTTS 參照。
- 排除過：Python 3.9 與語法相容性、Torch / Torchaudio 二進位符號不匹配、Torch 2.6 weight loading 行為。
- **最後關鍵 root cause**：`transformers` 的 `GenerationMixin` API／繼承變動，造成 `GPT2InferenceModel.generate` 消失。使用者回報 `pip install transformers==4.37.2` 後成功。
- 以中文句子及短故事作為語音合成測試的設計已提出，**但未提供對聲紋相似度、即時對話延遲或影片嘴型的實測數據**。

## 5. 明確不做
- 不冒充現在真人、不聲稱具備本人意識。
- 不自動捏造私人回憶、感情承諾、法律或醫療建議。
- 不把聲紋、人臉、家庭原始資料或 OpenAI API Key 放在公開 GitHub。
- 不以「影片即時生成」作為 MVP 必須條件；先完成即時**對話**與輕量動畫。
- 不假設 ChatGPT consumer App 的訂閱等同 OpenAI API 額度或能更改 ChatGPT App 官方語音。

## 6. 重要設計原則
- **Consent & legacy**：本人建立授權與受託管理；家人可控制對話、保存與終止。
- **Truthful persona**：有來源就引用，沒有來源就說明這是 AI 的推測或一般建議。
- **Kid-safe**：適齡、避免形成排他依附，鼓勵與真實家人溝通。
- **Portability**：可替換的 API，文字/音訊/記憶標準格式，本地資料不受 SaaS 綁定。
